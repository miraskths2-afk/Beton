# Сводный архив: патчи 4–16

Здесь собраны все файлы, которые менялись начиная с патча 4 и до
патча 16 включительно — 22 файла кода/конфигурации + 2 SQL-скрипта.
Более ранние патчи (1–3) в этот архив не входят — если вы их ещё не
применяли, они уже должны быть в проекте с прошлых шагов.

## Как применить

1. Распакуйте `probeton_combined.zip`.
2. Скопируйте папку `probeton` из архива **поверх** вашей папки проекта
   (Ctrl+A, Ctrl+C внутри распакованной папки → Ctrl+V в папку проекта,
   подтвердить замену).
3. **Удалите вручную** файл (он не используется с патча 7, но сам не
   удалится при копировании поверх):
   ```
   src/components/PlantMap.jsx
   ```
4. Вставьте в Supabase → SQL Editor → Run оба скрипта (если ещё не
   вставляли раньше):
   - `supabase_order_comment.sql`
   - `supabase_driver_payment.sql`
5. Установите зависимости и проверьте:
   ```bash
   npm install
   npm run dev
   ```
6. Когда всё устроит — как обычно:
   ```bash
   git add .
   git commit -m "Merge patches 4-16"
   git push
   ```
