## Как применить

1. Распакуйте `probeton_combined_49-52.zip`.
2. Скопируйте папку `probeton` из архива поверх вашей папки проекта
   (с заменой) — **обязательно вместе с папкой `public`**, там новые
   PNG-иконки для установки приложения.
3. Проверьте:
   ```bash
   npm install
   npm run build
   ```
4. Залейте:
   ```bash
   git add .
   git commit -m "Merge patches 49-52"
   git push
   ```
