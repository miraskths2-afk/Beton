# Сводный архив: патчи 17–21

9 файлов кода + 2 SQL-скрипта. Все файлы кода — **замена** существующих
(новых файлов среди них нет, кроме тех, что вы уже получали в патчах
20-21 — LocationPicker.jsx и MyIntercepts.jsx, но раз они через
патчи уже были добавлены, здесь тоже просто перезапишутся тем же).

## Как применить

1. Распакуйте `probeton_combined_17-21.zip`.
2. Скопируйте папку `probeton` из архива поверх вашей папки проекта
   (с заменой файлов).
3. Вставьте в Supabase → SQL Editor → Run **оба** скрипта (если ещё
   не вставляли):
   - `supabase_master_check.sql` — сводная проверка всей базы
     (безопасно запускать даже повторно)
   - `supabase_delivery_location.sql` — координаты точки доставки
4. Проверьте:
   ```bash
   npm install
   npm run dev
   ```
5. Залейте:
   ```bash
   git add .
   git commit -m "Merge patches 17-21"
   git push
   ```
