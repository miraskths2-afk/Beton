## Как применить

1. Распакуйте `probeton_combined_38-48.zip`.
2. Скопируйте папку `probeton` из архива поверх вашей папки проекта
   (с заменой файлов).
3. Вставьте `supabase_master_check_v3.sql` в Supabase → SQL Editor →
   Run — можно смело запускать, даже если что-то из старых отдельных
   SQL-скриптов уже было вставлено раньше.
4. Проверьте:
   ```bash
   npm install
   npm run build
   ```
5. Залейте:
   ```bash
   git add .
   git commit -m "Merge patches 38-48"
   git push
   ```
