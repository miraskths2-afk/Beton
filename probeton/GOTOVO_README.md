# PROBETON — готовый проект (Base44 → Supabase)

Я сам собрал весь ваш "текстовый бардак" обратно в нормальную структуру
папок и файлов и сразу внёс туда все правки для работы без Base44.
Вам осталось совсем немного.

## Шаг 1. Распакуйте архив

Разархивируйте `probeton.zip` куда угодно (например на Рабочий стол).
Внутри будет папка `probeton` — это уже полностью готовый проект.

## Шаг 2. Откройте в VS Code

VS Code → File → Open Folder… → выберите папку `probeton`.

## Шаг 3. Создайте таблицы в Supabase (если ещё не делали)

1. Откройте ваш проект на supabase.com → слева "SQL Editor"
2. Откройте файл `probeton/supabase_schema.sql` (можно прямо в VS Code),
   скопируйте всё содержимое
3. Вставьте в SQL Editor на сайте Supabase → нажмите "Run"

## Шаг 4. Проверьте файл .env

В папке проекта уже лежит файл `.env` с вашими данными от Supabase —
я его сразу заполнил вашими значениями. Открывать и трогать не обязательно,
разве что захотите свериться.

## Шаг 5. Установите зависимости и запустите

В VS Code откройте терминал (Terminal → New Terminal) и по очереди
выполните:

```bash
npm install
npm run dev
```

Откройте ссылку, которую покажет терминал (обычно `http://localhost:5173`).
Должен появиться экран "Кто вы?" → выбор роли → ввод номера телефона →
приложение.

## Шаг 6. Сделайте себя админом

Чтобы попасть в админ-панель:
1. Зайдите в Supabase → Table Editor → таблица `app_users`
2. Найдите свою строку по номеру телефона
3. В колонке `role` впишите `admin`, сохраните
4. Обновите страницу сайта — появится доступ к админке

## Шаг 7. Выложите на GitHub и Vercel (бесплатно)

```bash
git init
git add .
git commit -m "PROBETON on Supabase"
```

На github.com: New repository → любое имя → Create (ничего лишнего не
добавляйте). Дальше выполните команды, которые покажет GitHub, например:

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/probeton.git
git branch -M main
git push -u origin main
```

Затем на vercel.com → Add New → Project → выберите репозиторий `probeton`.
Перед нажатием Deploy откройте "Environment Variables" и добавьте:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

(значения возьмите из вашего `.env`). Нажмите Deploy — через пару минут
получите рабочую ссылку на сайт.

## Если что-то не работает

Присылайте сюда точный текст ошибки (из терминала или из консоли браузера,
F12 → Console) — разберём.
