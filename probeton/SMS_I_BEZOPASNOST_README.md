# Вход по SMS, закрытая база и платный Кубовик — как включить

Эти изменения работают только вместе: новая версия сайта + SQL-файл +
настройка SMS. Делайте по шагам, лучше вечером, когда мало заказов.

## Что изменилось

- **Вход по SMS-коду.** Номер → код из SMS → вход. Без кода войти под
  чужим номером нельзя. Старые аккаунты сохраняются: при первом входе
  по SMS аккаунт находится по номеру (формат 8 / +7 не важен).
- **База закрыта.** Без входа по SMS из базы ничего нельзя прочитать.
  Заказчик видит только свои заказы, водитель — свободные и свои,
  админ — всё. Чёрный список видит только админ.
- **Деньги защищены на сервере.** Только админ может подтвердить оплату
  сбора, закрыть заказ, назначить водителя, выдать одобрение. Нельзя
  уменьшить объём заказа после принятия (от него считается сбор).
- **Баланс водителя.** Водитель переводит деньги на ваш Kaspi, в
  разделе «Баланс» нажимает «Я перевёл», вы на Главной нажимаете
  «Деньги пришли, зачислить».
- **Платный Кубовик.** Публикация остатка списывает с баланса цену
  публикации (по умолчанию 1 000 ₸, меняется на Главной у админа).
  Опубликованный остаток нельзя переписать под новый — только
  опубликовать новый.

## Шаг 1. SMS-провайдер (один на выбор)

- **SMSC.kz** — smsc.kz: регистрация, пополнить баланс. Понадобятся
  логин и пароль (в настройках можно задать отдельный API-пароль).
- **Mobizon** — mobizon.kz: регистрация, пополнить баланс, в разделе
  API скопировать ключ.

Имя отправителя (например PROBETON) регистрируется у провайдера
отдельно и занимает время. Пока его нет, SMS уходят от имени по
умолчанию — это нормально.

## Шаг 2. Supabase: включить вход по телефону

1. Authentication → Sign In / Providers → **Phone** → включить.
   Если форма требует выбрать провайдера SMS, выберите любой — SMS
   всё равно будет отправлять наш хук из шага 3.
2. Там же: длина кода 6, срок действия 300 секунд.
3. Для проверки без трат на SMS добавьте там же в «Test phone numbers»
   свой номер и постоянный код, например `77001234567=123456`.
4. Authentication → Rate Limits: ограничьте число SMS в час (например
   30), чтобы никто не «сжёг» ваш баланс SMS.

## Шаг 3. Supabase: хук отправки SMS

1. Authentication → Hooks → **Send SMS hook** → тип **HTTPS**.
2. URL: `https://ВАШ-САЙТ.vercel.app/api/send-sms`
   (ваш настоящий адрес сайта).
3. Нажмите «Generate secret», скопируйте секрет (`v1,whsec_...`).

## Шаг 4. Vercel: переменные окружения

Project → Settings → Environment Variables, добавить:

| Имя | Значение |
|---|---|
| `SEND_SMS_HOOK_SECRET` | секрет из шага 3 |
| `SMS_PROVIDER` | `smsc` или `mobizon` |
| `SMSC_LOGIN`, `SMSC_PASSWORD` | для SMSC.kz |
| `MOBIZON_API_KEY` | для Mobizon |
| `SMS_SENDER` | имя отправителя, только если уже зарегистрировано |

## Шаг 5. Выкатить

1. Смержить pull request (Vercel сам задеплоит новую версию).
2. Сразу после этого в Supabase → SQL Editor вставить весь файл
   `supabase_security_v4.sql` → Run.
3. В Table Editor → `app_settings` поменять `kaspi_details` на ваши
   настоящие реквизиты (или на Главной админа → «Цена публикации
   остатка»).
4. Выйти и войти заново по SMS со своего админского номера.
5. Всем пользователям нужно будет один раз войти по SMS. Водителям
   после выхода, как и раньше, нужно ваше одобрение.

## Если что-то сломалось

1. В Vercel → Deployments откатить на предыдущую версию.
2. В SQL Editor запустить `supabase_security_v4_rollback.sql`, затем
   `supabase_master_check_v3.sql`. Всё вернётся как было, данные
   (балансы, заявки) не пропадут.
