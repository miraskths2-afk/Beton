# Сводный архив: патчи 27–37 (всё новое одним файлом)

14 файлов кода (все — замена существующих, кроме OfflineDriversList.jsx
и vercel.json — но раз получали их раньше, просто перезапишутся тем же)
+ 1 SQL-скрипт, который включает **вообще всё** за весь проект
(можно запускать даже если раньше не вставляли ни одного из
предыдущих 13 отдельных SQL-файлов — он всё содержит).

## Установка

1. Распакуйте `probeton_combined_27-37.zip`.
2. Скопируйте папку `probeton` из архива поверх вашей папки проекта
   (с заменой).
3. Вставьте `supabase_master_check_v2.sql` в Supabase → SQL Editor →
   Run (безопасно, можно запускать хоть каждый день).
4. Дополнительно положите `vercel.json` в **корень проекта** (не в
   src), если ещё не лежит с прошлого раза.
5. Проверьте:
   ```bash
   npm install
   npm run build
   ```
6. Залейте:
   ```bash
   git add .
   git commit -m "Merge patches 27-37"
   git push
   ```

## Что изменилось (по порядку)

1. **Исправлена ошибка 404** при прямом переходе по ссылке (например
   `/profile`) — добавлен `vercel.json`.
2. **Исправлен белый зависший экран** при входе — был баг с порядком
   React-хуков в `ProtectedRoute.jsx` (моя ошибка из прошлого патча).
3. **Клик по заявке у админа** теперь открывает отдельную страницу с
   полной информацией.
4. **История действий по заказу** — время создания, время принятия
   водителем, время завершения.
5. **Ссылка "на карте"** у адреса теперь видна и водителю, не только
   админу.
6. **Полное управление заявкой** (смена статуса, удаление) прямо со
   страницы заказа — как в Кубовике.
7. **Встроенная карта** (не просто ссылка) на страницах заказа и
   остатка.
8. **На карте у заказчика** видны все миксеристы на линии, но **без**
   номера телефона и госномера — это видно только админу.
9. **Управление водителями на карте у админа** — "Убрать с линии" и
   "Удалить аккаунт" + отдельная таблица водителей, которые сейчас не
   на линии.
10. **"Заказ в один клик"** у заказчика теперь свёрнут по умолчанию —
    открывается только по кнопке "Заказать".
11. **Исправлен расчёт баланса водителя** — раньше был фиксированный
    5000₸ за любую доставку независимо от объёма, теперь честно
    кубы × 1000₸.
12. **"Баланс" переименован в "Статистика"** — убрана формулировка
    "доступно к выплате", теперь просто количество и сумма
    выполненных заявок.
13. **"Остатки" разбиты на 3 вкладки**: Новые / В работе / Выполнены
    — и у водителя, и в общей ленте.
