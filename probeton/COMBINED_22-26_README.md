# Сводный архив: патчи 22–26

11 файлов кода (все — замена существующих, кроме LeftoverDetail.jsx,
PendingScreen.jsx и StaticPointMap.jsx — это новые файлы, но раз вы уже
получали их в отдельных патчах, здесь они просто перезапишутся тем же)
+ 2 SQL-скрипта.

## Как применить

1. Распакуйте `probeton_combined_22-26.zip`.
2. Скопируйте папку `probeton` из архива поверх вашей папки проекта
   (с заменой файлов).
3. Вставьте в Supabase → SQL Editor → Run **оба** скрипта (если ещё
   не вставляли):
   - `supabase_intercept_location.sql` — координаты перехвата остатка
   - `supabase_client_grandfather.sql` — разово одобряет уже
     существующих заказчиков (обязательно выполнить, иначе все
     текущие заказчики окажутся заблокированы при следующем входе)
4. Проверьте:
   ```bash
   npm install
   npm run dev
   ```
5. Залейте:
   ```bash
   git add .
   git commit -m "Merge patches 22-26"
   git push
   ```

## Что внутри (кратко)

- Админ в режиме "Водитель" получает полный доступ без одобрения
- Водитель видит на карте, откуда прораб перехватил остаток
- Повторный вход после выхода из аккаунта требует одобрения админом
  (для всех ролей, кроме самого админа)
- "Мой заказ" у заказчика больше не требует вводить номер и не
  позволяет смотреть чужие заказы
- Остатки в "Кубовике" открываются на отдельной странице с управлением
  (сменить статус, удалить)
